# Contributing

1. Keep skills portable and free of organization-specific claims.
2. Preserve source precedence: local workspace decisions beat generic defaults.
3. Add or update output and trigger evals with every behaviour change.
4. Run `python3 scripts/check.py`, package, and run package checks.
5. Do not publish source exports, credentials, example customer data, or internal tool names.
6. Cite primary sources for new framework claims.
