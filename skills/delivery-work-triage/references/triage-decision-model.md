# Triage decision model

| Disposition | Use when | Required record |
|---|---|---|
| Accept | Valid work for this team; enough context to enter its workflow | why, owner/accountable hat, type, proposed neighbourhood |
| Needs information | A specific answer/evidence is required before disposition | targeted question, respondent, revisit trigger |
| Return for refinement | Intent is valid but too vague/risky to size or order | missing decisions/artefacts and accountable owner |
| Duplicate | Existing canonical issue represents the same need | canonical link and any unique evidence moved/preserved |
| Snooze | Valid revisit condition exists but no action is useful now | date/event trigger and reason |
| Decline/close | Team does not intend to act | clear reason; alternative route if known |
| Route | Another team/system owns the next decision | destination and handoff context |

## Relative ordering prompts

Use evidence, not a universal score:

1. Fixed external obligation or time-critical harm.
2. Contribution to the current objective/outcome.
3. Material risk reduction or learning.
4. Dependency/unblocking effect.
5. Cost of delay and opportunity trade-off.

The accountable owner decides order. Record disagreements rather than averaging them into a fake number.
